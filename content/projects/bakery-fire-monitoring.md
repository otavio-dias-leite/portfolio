## Project overview

Developed for the IFF Saber Fazer Saber fair, this project explores monitoring fire-related risks in a bakery environment. The goal is to support early awareness of potentially dangerous conditions in a workplace where heat-generating equipment is part of daily operation.

## Project details

- Monitoring of fire-related risk conditions.
- Electronic monitoring and alert-system concepts.
- Application of technical solutions to a real work environment.
